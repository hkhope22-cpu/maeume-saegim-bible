# 마음에 새김

크롬과 모바일 브라우저에서 실행되는 성경 전체 암송 게임입니다. 파일 업로드 없이도 **한국어 성경 1910** 66권 30,991절을 바로 선택할 수 있고, 핵심 12구절·에베소서 주간 진도·누적 암송·녹음 인증과 친구 그룹 현황판을 함께 사용할 수 있습니다.

공유용 공개 주소: <https://bible-maeum.vercel.app>

## 실행

`크롬에서 실행.bat`을 더블클릭하세요. 이 앱은 성경 데이터 파일을 불러오기 때문에 `index.html`을 파일로 직접 여는 대신 로컬 웹서버로 실행해야 합니다.

직접 실행하려면 이 폴더에서 다음 명령을 사용합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local-server.ps1 -Port 4173
```

그다음 `http://127.0.0.1:4173`에 접속합니다.

## GitHub와 Vercel 배포

Vercel은 `dist/client`의 정적 화면과 `api/team.js`의 그룹 API를 함께 배포합니다. 그룹 정보·진도·인증 기록·선택해 올린 녹음은 프로젝트에 연결한 **비공개 Vercel Blob 저장소**에 보관됩니다. 로컬 학습 기록과 개인 설정은 계속 각 브라우저에만 저장됩니다.

처음 배포하는 Vercel 프로젝트에는 다음처럼 비공개 Blob 저장소를 한 번 연결해야 합니다.

```powershell
vercel blob create-store maeume-saegim-team --access private --yes
```

이 명령이 프로젝트 환경 변수 `BLOB_READ_WRITE_TOKEN`을 연결합니다. 현재 운영 프로젝트에는 이미 연결되어 있습니다. GitHub 저장소의 `main` 브랜치와 Vercel을 연결하면 이후 변경도 자동으로 다시 배포됩니다.

## 친구 그룹 암송

`함께 암송` 메뉴에서 그룹장이 그룹을 만들고, 8자리 코드가 포함된 초대 링크를 친구에게 보낼 수 있습니다.

- 회원가입 없이 그룹 이름·표시 이름·초대코드로 참여
- 핵심 12구절, 이번 주 새 진도, 누적 암송을 기본 그룹 진도로 생성
- 그룹장이 주차별 새 진도와 암송 범위를 계속 추가
- 진도별 최근 7일 `친구 × 날짜` 인증표
- 오늘 인증한 친구 수, 최근 7일 인증 수, 최근 인증 피드
- 완료 표시만 올리거나 최대 3MB 녹음 파일을 선택하여 비공개 업로드
- 앱에서 방금 녹음한 음성을 곧바로 그룹 인증에 사용

초대코드는 간편한 소그룹 공유를 위한 접근 장치이며 엄격한 계정 인증을 대신하지 않습니다. 필요한 친구에게만 링크를 전달하세요. 인증 작성은 참여한 기기에 별도로 발급한 멤버 키를 검사하며, 녹음 파일은 공개 Blob URL로 노출하지 않고 서버 함수를 통해서만 재생합니다.

## 성경 전체 암송

왼쪽 메뉴의 `성경 전체`에서 다음을 선택할 수 있습니다.

- 구약 39권·신약 27권
- 성경, 장, 시작 절, 마지막 절
- 빈칸 채우기, 첫글자 힌트, 순서 맞추기
- 선택 범위 또는 한 장 전체
- 장 미리보기에서 한 절만 바로 연습

공개 성경 본문은 사이트 파일에 포함되어 있어 방문자가 따로 업로드할 필요가 없습니다. 학습 기록과 개인 설정만 각 브라우저의 로컬 저장소에 보관됩니다.

## 저작권과 본문 출처

기본 본문은 eBible.org가 퍼블릭 도메인으로 배포하는 **The Holy Bible in Korean, 1910 translation**입니다.

- 공식 안내: <https://ebible.org/find/details.php?id=kor>
- 퍼블릭 도메인 설명: <https://ebible.org/publicdomain.htm>
- 개발자용 원본: <https://ebible.org/Scriptures/kor_vpl.zip>

이 번역은 개역개정이 아닌 옛 한국어 번역입니다. 개역개정 등 별도 허락이 필요한 번역은 웹에서 무단으로 크롤링하거나 모든 방문자에게 배포하지 않습니다.

사이트 자체는 검색엔진과 자동 수집을 허용하지 않는 운영 정책을 적용합니다. `robots.txt`, HTML의 robots 메타 태그, 모든 응답의 `X-Robots-Tag` 헤더가 함께 `noindex`와 크롤링 차단을 요청합니다. 이는 규칙을 따르는 검색엔진·크롤러를 위한 표준 차단 장치이며, 의도적으로 우회하는 수집 프로그램까지 기술적으로 완전히 막는 보안 장치는 아닙니다. 또한 이 정책은 기본 공개역 본문 자체의 퍼블릭 도메인 지위를 변경하지 않습니다.

사용자가 정당하게 이용할 수 있는 별도 번역이 있다면 `말씀 보관함 → 내 번역 추가`에서 에베소서와 핵심 말씀을 입력할 수 있습니다. 이 개인 입력 본문은 공개역보다 우선 적용되지만 현재 브라우저에만 저장되고 다른 방문자에게 배포되지 않습니다.

## 공개 본문 업데이트

공식 eBible.org 배포본을 다시 내려받아 앱용 JSON으로 변환하려면 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-public-domain-bible.ps1
```

스크립트는 공식 VPL 압축 파일을 다운로드하고, 66권과 퍼블릭 도메인 표시를 유지한 `data/kor1910.json`을 생성합니다. 일반 방문자는 이 작업을 할 필요가 없습니다.

## 주요 기능

- 핵심 12구절 매일 암송
- 에베소서 2:10–18 기본 주간 진도와 이전 진도 자동 누적
- 입력한 진도 분량만 학습
- 기억을 단단하게 하는 세 가지 게임을 시작하기 전에 이번 주 진도·이전 누적·에베소서 직접 선택·성경 전체 중 범위 선택
- 에베소서 직접 선택에서 시작 장·절과 마지막 장·절을 지정해 `2:20–3:5`처럼 장을 넘나드는 연속 범위 학습
- 새 진도·누적 암송·녹음 인증 시간을 각각 지정하는 미완료 알림
- 빈칸 채우기, 단어별 첫글자 힌트, 전체 구절 힌트, 순서 맞추기
- 띄어쓰기와 문장부호를 제외한 실제 글자 기준 채점
- 틀린 글자 색상 표시와 오답노트 자동 저장
- 오답 구절을 힌트 없이 두 번 연속 맞힐 때까지 반복학습
- Chrome 실시간 음성인식으로 암송을 텍스트화하고 다른 글자를 빨간색으로 표시
- 확정된 오답 구간에서 소리 알림 또는 자동 멈춤을 선택하고 음성 답안을 바로 채점
- 마이크 녹음, 재생, 파일 저장 및 모바일 공유
- 초대코드 기반 친구 그룹, 그룹장 진도 추가, 진도별 7일 인증 현황판
- 완료 인증과 선택적 비공개 녹음 업로드
- 연속 학습일, 익숙함, 최근 기록
- JSON 백업 내보내기·불러오기
- 반응형 모바일 화면

별도로 저장하는 녹음 파일은 자동 전송되지 않습니다. 사용자가 `팀에 인증 올리기`를 직접 선택한 경우에만 선택한 파일이 그룹 저장소로 이동합니다. 실시간 음성인식은 별도 파일을 저장하지 않지만 Chrome의 인식 서비스를 사용하므로 처리 과정에서 음성이 브라우저 서비스 제공자에게 전송될 수 있고 인터넷 연결이 필요할 수 있습니다. 브라우저가 완전히 종료된 동안에는 정시 알림을 실행할 수 없으며, 앱을 다시 열면 놓친 미완료 항목을 확인합니다.

## 검증

로컬 서버가 실행 중일 때 다음 스모크 테스트로 66권 로딩, 모바일 그룹 진입, 선택 범위 게임 시작을 확인할 수 있습니다.

```powershell
node .\scripts\smoke-test.cjs http://127.0.0.1:4173/
```
