# 마음에 새김

크롬과 모바일 브라우저에서 실행되는 성경 전체 암송 게임입니다. 파일 업로드 없이도 **한국어 성경 1910** 66권 30,991절을 바로 선택할 수 있고, 기존의 핵심 12구절·에베소서 주간 진도·누적 암송·녹음 인증 흐름도 그대로 사용할 수 있습니다.

## 실행

`크롬에서 실행.bat`을 더블클릭하세요. 이 앱은 성경 데이터 파일을 불러오기 때문에 `index.html`을 파일로 직접 여는 대신 로컬 웹서버로 실행해야 합니다.

직접 실행하려면 이 폴더에서 다음 명령을 사용합니다.

```powershell
python -m http.server 4173
```

그다음 `http://127.0.0.1:4173`에 접속합니다.

## 성경 전체 암송

왼쪽 메뉴의 `성경 전체`에서 다음을 선택할 수 있습니다.

- 구약 39권·신약 27권
- 성경, 장, 시작 절, 마지막 절
- 빈칸 채우기, 첫글자 힌트, 순서 맞추기
- 선택 범위 또는 한 장 전체
- 장 미리보기에서 한 절만 바로 연습

공개 성경 본문은 사이트 파일에 포함되어 있어 방문자가 따로 업로드할 필요가 없습니다. 학습 기록과 개인 설정만 각 브라우저의 로컬 저장소에 보관됩니다.

## 저작권과 본문 출처

기본 본문은 eBible.org가 퍼블릭 도메인으로 배포하는 **The Holy Bible in Korean, 1910 translation**입니다.

- 공식 안내: <https://ebible.org/find/details.php?id=kor>
- 퍼블릭 도메인 설명: <https://ebible.org/publicdomain.htm>
- 개발자용 원본: <https://ebible.org/Scriptures/kor_vpl.zip>

이 번역은 개역개정이 아닌 옛 한국어 번역입니다. 개역개정 등 별도 허락이 필요한 번역은 웹에서 무단으로 크롤링하거나 모든 방문자에게 배포하지 않습니다.

사용자가 정당하게 이용할 수 있는 별도 번역이 있다면 `말씀 보관함 → 내 번역 추가`에서 에베소서와 핵심 말씀을 입력할 수 있습니다. 이 개인 입력 본문은 공개역보다 우선 적용되지만 현재 브라우저에만 저장되고 다른 방문자에게 배포되지 않습니다.

## 공개 본문 업데이트

공식 eBible.org 배포본을 다시 내려받아 앱용 JSON으로 변환하려면 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-public-domain-bible.ps1
```

스크립트는 공식 VPL 압축 파일을 다운로드하고, 66권과 퍼블릭 도메인 표시를 유지한 `data/kor1910.json`을 생성합니다. 일반 방문자는 이 작업을 할 필요가 없습니다.

## 주요 기능

- 핵심 12구절 매일 암송
- 에베소서 2:10–18 기본 주간 진도와 이전 진도 자동 누적
- 입력한 진도 분량만 학습
- 새 진도·누적 암송·녹음 인증 시간을 각각 지정하는 미완료 알림
- 빈칸 채우기, 단어별 첫글자 힌트, 전체 구절 힌트, 순서 맞추기
- 마이크 녹음, 재생, 파일 저장 및 모바일 공유
- 연속 학습일, 익숙함, 최근 기록
- JSON 백업 내보내기·불러오기
- 반응형 모바일 화면

녹음은 외부 서버로 자동 전송되지 않습니다. 사용자가 직접 저장하거나 공유할 때만 기기 밖으로 이동합니다. 브라우저가 완전히 종료된 동안에는 정시 알림을 실행할 수 없으며, 앱을 다시 열면 놓친 미완료 항목을 확인합니다.

## 검증

로컬 서버가 실행 중일 때 다음 스모크 테스트로 66권 로딩, 모바일 선택기, 선택 범위 게임 시작을 확인할 수 있습니다.

```powershell
node .\scripts\smoke-test.cjs http://127.0.0.1:4173/
```
