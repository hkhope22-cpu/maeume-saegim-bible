개역개정 등 별도 허락이 필요한 번역본은 웹에서 무단 크롤링하지 않습니다. 사용자가 정당하게 이용할 수 있는 본문을 직접 추가한 경우에만 해당 본문이 현재 브라우저에 저장되며 다른 방문자에게 배포되지 않습니다.

이 사이트의 검색 색인과 자동화된 크롤링은 허용하지 않습니다. robots.txt, 페이지 메타 태그와 응답 헤더로 일반 검색엔진과 크롤러의 접근을 차단합니다. 이 조치는 사이트 운영 정책이며, 기본 공개역 본문 자체의 퍼블릭 도메인 지위는 바꾸지 않습니다.

개인 녹음은 자동 업로드되지 않습니다. 사용자가 팀에 인증 올리기를 직접 선택한 경우에만 그룹 이름·진도·인증 기록과 선택한 녹음이 Vercel 비공개 저장소에 전송됩니다. 초대코드를 받은 그룹 참여자는 해당 그룹의 인증과 녹음을 확인할 수 있으므로, 필요한 친구에게만 코드를 공유해 주세요.

게임의 실시간 음성인식은 브라우저가 제공하는 인식 서비스를 사용하며, Chrome 환경에서는 인식 처리를 위해 음성이 서비스 제공자의 서버로 전송될 수 있습니다. 공용 기기에서는 사용 후 브라우저 데이터를 삭제해 주세요.
